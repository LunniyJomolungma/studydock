# Provenance

The public README of [aishashafiq/smart-study-planner](https://github.com/aishashafiq/smart-study-planner) was consulted for the general category of a desktop study planner.

StudyDock's source, interface layout, scheduling logic, demo data, documentation and tests were written from scratch with AI assistance. No source code, images, icons, fonts or other assets from the reference were incorporated. StudyDock focuses on deadline capacity and unallocated work instead of reproducing the reference application's feature set.

Application code uses only the Java standard library and Swing. A JDK and GitHub Actions are development tools with their own terms; the JDK is not bundled in this repository. The preview is rendered from StudyDock's actual Swing panel with sample data. This document does not claim that the broad idea of a planner is novel.
